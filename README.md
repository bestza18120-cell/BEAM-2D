# Beam 2D — PWA

แอปคำนวณคาน 2D (FEM) ที่ติดตั้งลงเครื่องได้ ใช้ออฟไลน์ได้ และอัปเดตอัตโนมัติ

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (คำนวณ, กราฟ, Save/Open) |
| `manifest.json` | ชื่อแอป ไอคอน สีธีม และการผูกไฟล์ `.beam` |
| `sw.js` | Service worker ที่เก็บไฟล์ไว้ใช้ออฟไลน์และตรวจหาเวอร์ชันใหม่ — **เลขเวอร์ชันอยู่ที่นี่** |
| `icons/` | ไอคอนแอป |

> ถ้าเปิด `index.html` ด้วยการดับเบิลคลิก (`file://`) แอปจะคำนวณได้ปกติ แต่จะไม่มีปุ่มติดตั้ง ไม่ทำงานออฟไลน์ และไม่อัปเดตอัตโนมัติ ฟีเจอร์ PWA ต้องเปิดผ่าน **https** เท่านั้น

## ขึ้นเว็บด้วย GitHub Pages (ครั้งแรก, ฟรี)

1. สมัครหรือล็อกอิน github.com แล้วกด **New repository** ตั้งชื่อ เช่น `beam2d` และเลือก **Public** (บัญชีฟรีใช้ Pages กับ repo private ไม่ได้)
2. ในหน้า repo กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `icons`) จากนั้นกด **Commit changes**
3. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** เลือก Branch: `main` / `(root)` แล้วกด **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/beam2d/`
5. ส่งลิงก์นี้ให้ผู้ใช้ เปิดใน Chrome/Edge แล้วกดปุ่ม **⬇ ติดตั้งแอป** ในแอป (หรือไอคอน ⊕ ที่ช่อง URL)

ทางเลือกอื่นที่ทำแบบเดียวกันได้: Netlify Drop (ลากโฟลเดอร์ไปวาง), Cloudflare Pages

## ออก patch / อัปเดตเวอร์ชัน

1. แก้ `index.html` (หรือไฟล์อื่น) ตามต้องการ
2. **เปิด `sw.js` แล้วเปลี่ยน `const VERSION = '1.0.0';` เป็นเลขใหม่** เช่น `'1.0.1'`
   ขั้นนี้จำเป็นทุกครั้ง ถ้าไม่เปลี่ยน เบราว์เซอร์ของผู้ใช้จะไม่รู้ว่ามีเวอร์ชันใหม่
3. อัปโหลดไฟล์ที่แก้ทับใน GitHub (Add file → Upload files → Commit)
4. ครั้งถัดไปที่ผู้ใช้เปิดแอป (หรือสลับกลับมาที่แอป) จะเห็นแถบ **"🔔 มี Beam 2D เวอร์ชันใหม่ → อัปเดตเลย"** กดแล้วแอปจะรีโหลดเป็นเวอร์ชันใหม่ งานที่ทำค้างไว้ไม่หาย

แนะนำให้ตั้งเลขเวอร์ชันแบบ `major.minor.patch`
- `1.0.1` แก้บั๊ก
- `1.1.0` เพิ่มฟีเจอร์
- `2.0.0` เปลี่ยนใหญ่

## ไฟล์โปรเจกต์ `.beam`

- **Save As / Save** บันทึกเฉพาะข้อมูล (ความยาวคาน, support, แรง, load combination) เป็นไฟล์ `.beam` (ข้างในเป็น JSON) ไฟล์จึงเปิดได้ในแอปทุกเวอร์ชันต่อจากนี้
- **📂 เปิด** เปิดไฟล์ `.beam` ได้ และยัง **นำเข้าไฟล์ `.html` ที่เซฟจากเวอร์ชันเก่า** ได้ด้วย
- คีย์ลัด: `Ctrl+S` = Save, `Ctrl+Shift+S` = Save As, `Ctrl+O` = เปิด
- แอปเซฟงานล่าสุดไว้ในเครื่องให้อัตโนมัติ (autosave) ปิดแอปแล้วเปิดใหม่ งานยังอยู่
- เมื่อติดตั้งแอปบน Windows ผ่าน Chrome/Edge แล้ว ดับเบิลคลิกไฟล์ `.beam` จะเปิดในแอปได้
- **Save ทับไฟล์เดิม** ใช้ได้ใน Chrome/Edge ส่วน Safari/Firefox จะเป็นการดาวน์โหลดไฟล์ใหม่แทน

### ถ้าวันหลังเปลี่ยนโครงสร้างข้อมูล

ใน `index.html` ให้เพิ่ม `FILE_FORMAT` (เช่น 1 → 2) แล้วเขียนโค้ดแปลงข้อมูลเก่าใน `migrateState()` ไฟล์ `.beam` เก่าจะเปิดได้ต่อ ส่วนไฟล์ที่มาจากเวอร์ชันใหม่กว่าแอปที่ผู้ใช้มีอยู่ แอปจะเตือนให้อัปเดตก่อน
